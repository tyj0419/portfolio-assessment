# 投资组合分析与调仓模拟

单用户、单组合、固定行情的本地全栈原型。首页包含组合概览、集中度提醒、调仓对比和已保存方案。

## 提交说明

- **实际投入时长**为1 小时 30 分钟。首轮 Codex 从读取任务到首次打包约 6 分钟，这是工具侧的墙钟时间，单独记录。
- **AI 工具**为 Codex，用于规则梳理、方案设计、代码实现、测试与文档整理。协作和实测反馈见 [DESIGN.md](DESIGN.md)。
- **未完成项**方面，FR-01 至 FR-05 已实现，AC-01 至 AC-05 已通过。移动端和其他浏览器尚未验证，浏览器回归脚本未随项目交付。测试范围见 [VERIFY.md](VERIFY.md)。

## 启动

环境为 Node.js 24，验证版本为 24.22.1。项目无第三方依赖，解压后在项目根目录运行：

```sh
node server.js
```

打开 [http://127.0.0.1:3000](http://127.0.0.1:3000)。如有 npm，也可使用 npm start。无需额外安装和初始化。程序读取随包提供的官方示例 data/portfolio.json，首次启动创建 runtime/，方案保存在其中。重启后请保留该目录。端口可通过 PORT 环境变量设置。

## 复现核心流程

1. 首页确认总资产 100,000.00 元，初始现金 20,000.00 元。A01 和科技行业超限。
2. 卖出 A01 100 股，查看现金 30,000.00 元和两项提醒解除。
3. 接着买入 A02 100 股，查看现金 25,000.00 元及科技行业 55.00% 的提醒。
4. 输入方案名称并保存。刷新浏览器，或停止后再次运行启动命令。在「已保存方案」点击「重新打开」。
5. 查看重放后的结果，并核对上方原始持仓。点击「清空操作」可开始新的模拟。

运行自动验收：

```sh
node --test
```

测试会启动回环 HTTP 服务并用临时目录存储测试方案。
